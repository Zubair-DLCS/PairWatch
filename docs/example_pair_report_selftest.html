How to read this

These are signs of how the pair worked together, not grades. Looking is estimated from head direction with one webcam, so "same part of code" means roughly the same third of the screen. Talk is attributed by combining the microphone with mouth movement; quiet speech or a covered mouth can be missed. Use the report as a starting point for a conversation with the pair.
